Vendor-sold recipes, Classic

Sources: OctoWow DB + Wowhead Classic. One row per recipe. All vendors that sell it listed one per line.
Show vendors for: Neutral vendors show under both.
Vendor and recipe links go to Wowhead Classic. Purple links = only exists on OctoWow, so it links there.
Faction: Alliance / Horde = friendly to that side. Neutral = neither side hostile. Reputation requirements are not included in either source.
Disenchant column (Tailoring, Leatherworking, Blacksmithing, Engineering): derived from the crafted item's quality and item level (the ilvl stat, not the required level) using the WoWWiki disenchanting tables. Percentages are the chance per disenchant; "×" is the quantity range. Soulbound or special items that cannot be disenchanted in-game are not flagged. "-" = crafted item unknown.
Routes are estimates. The map positions, flight paths, boat and zeppelin times in this page are a hand-built model, not game data.
